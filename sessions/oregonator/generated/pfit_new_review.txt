The ODE system for the Oregonator Field-Noyes model has been extracted with the given frozen states and parameters. The RHS expressions for each state are provided.
The CSV columns X and Z directly map to the integrated states X and Z in the model. The standard deviations X_sd and Z_sd are provided but not used in the observable mapping.
The user provided a custom loss function that compares the simulated X and Z to the measured X and Z using the provided measurement standard deviations. The loss is calculated as the square root of the mean of the squared residuals.
