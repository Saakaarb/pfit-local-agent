I want to estimate the rates in a sphingolipid metabolism model, using the wild-type and Hai1a deletion data together. This is the model used to study the balance between apoptosis and apical cell extrusion by Armistead and colleagues (2024).

The four concentrations are Sphinga (sphinganine), Cer (ceramide), Sphingo (sphingosine) and S1P. Use the time and concentration units in the supplied data. Let H be a constant condition indicator: H = 1 for wild type and H = 0 for the mutant, so dH/dt = 0.

Here are the reaction rates, with ordinary multiplication:
r1 = k00 (1 + H alpha_cer)
r2 = k0 Sphinga
r3 = k1 Cer
r4 = k2 Sphingo
r5 = k_d Cer
r6 = k3 (1 - H alpha_hai1a) Sphingo
r7 = k4 S1P
r8 = k5 S1P

The balances are
dSphinga/dt = r1 - r2
dCer/dt = r2 - r3 + r4 - r5
dSphingo/dt = r3 - r4 - r6 + r7
dS1P/dt = r6 - r7 - r8.

All experiments start at time zero. For wild type, start with Sphinga = 0.000732, Cer = 0.988, Sphingo = 0.000395, S1P = 1.551, H = 1. For the mutant, use Sphinga = 0.000795, Cer = 0.822, Sphingo = 0.000364, S1P = 2.07, H = 0. These starting values are fixed.

The wild-type data are wt_r1.csv, wt_r2.csv, wt_r3.csv and wt_r4.csv. The mutant data are mutant_r1.csv, mutant_r2.csv, mutant_r3.csv and mutant_r4.csv. The r numbers only separate repeated measurements at each time; they do not mean that the same animal was followed across times. Each file has time, Sphinga_obs, Cer_obs and Sphingo_obs. These are direct measurements of Sphinga, Cer and Sphingo, respectively. S1P is unobserved in this fitting task; the source only has its baseline assay. Fit all eight files with one shared set of rates.

Estimate k00, k0, k_d, k1, k2, k3, k4 and k5, each on a logarithmic scale between 0.001 and 1000. Estimate alpha_hai1a on a linear scale from 0.5 to 0.999, and alpha_cer on a linear scale from -0.999 to -0.001. H is set by the experiment and is not a fitted rate.

Use an equally weighted average over the eight records. Within each record, divide the residual for each measured channel by that channel's largest absolute measured value, then take the square root of the mean squared normalized residuals over all three channels and times. Do not estimate measurement noise or add priors. The measurements are sparse, so I do not expect all rates to be uniquely identifiable. Use a stiff solver.
