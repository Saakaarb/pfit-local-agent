Fit the Sneyd-Dufour IP3 receptor model jointly to the nine clamp experiments
listed below. All experiments share the same fourteen rate constants.

The gating states are O, R, I1, S, A and I2. Initially R=1 and all the other
gating states are zero. Calcium (Ca) and IP3 stay constant during each
experiment. Each CSV contains time in seconds and measured open_probability.
The clamp concentrations are:
  file       IP3    Ca
  ca01.csv   10     0.1
  ca02.csv   10     0.2
  ca04.csv   10     0.4
  ca1.csv    10     1
  ca3.csv    10     3
  ca10.csv   10     10
  ip3.csv     3     0.4
  ip5.csv     5     0.4
  ip10.csv   10     0.4
You can carry IP3 and Ca as additional states with zero derivatives and set
their initial values to the clamp concentrations for each experiment.

Fit k1, k2, k3, k4, k_1, k_2, k_3, k_4, l2, l4, l6, l_2, l_4 and l_6.
Each rate lies between 0.001 and 100000, on a logarithmic scale. Underscored
names denote different rates: k_1 is not k1, and l_2 is not l2.

Define the equilibrium constants
  L1 = k_1 l2 / (k1 l_2)
  L3 = k_2 l4 / (k2 l_4)
  L5 = k_4 l6 / (k4 l_6)
and transition fluxes
  v0 = (k_2 + l_4 Ca)/(1 + Ca/L5) O
  v1 = (k2 L3 + l4 Ca)/(L3 + Ca (1 + L3/L1)) IP3 R
  v2 = (k1 L1 + l2) Ca/(L1 + Ca (1 + L1/L3)) R
  v3 = (k_1 + l_2) I1
  v4 = (k4 L5 + l6) Ca/(L5 + Ca) O
  v5 = L1 (k_4 + l_6)/(L1 + Ca) A
  v6 = (k1 L1 + l2) Ca/(L1 + Ca) A
  v7 = (k_1 + l_2) I2
  v8 = k3 L5/(L5 + Ca) O
  v9 = k_3 S

The differential equations are
  dO/dt = -v0 + v1 - v4 + v5 - v8 + v9
  dR/dt = v0 - v1 - v2 + v3
  dI1/dt = v2 - v3
  dS/dt = v8 - v9
  dA/dt = v4 - v5 - v6 + v7
  dI2/dt = v6 - v7

The observable open probability is Po = (0.9 A + 0.1 O)^4.
For each experiment, use plain RMSE between simulated Po and measured
open_probability. Average the nine RMSE values with equal weight for each
experiment. Save time, measured and simulated open probability separately
for every experiment. The rates span many orders of magnitude, so use a
stiff ODE solver.
