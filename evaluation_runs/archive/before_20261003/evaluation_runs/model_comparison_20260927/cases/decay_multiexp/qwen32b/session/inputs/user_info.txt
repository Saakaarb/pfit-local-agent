Please fit these two decay experiments together with the same rate constants.
The reaction is A -> B -> products:
  dA/dt = -k1 A
  dB/dt = k1 A - k2 B
Both k1 and k2 are positive, between 0.01 and 10, on a logarithmic scale.

The files decay_run_A.csv and decay_run_B.csv both contain time (seconds), A,
and B, in that order. Run A starts with A=1 and B=0 at t=0. Run B starts
with A=2 and B=0.5 at t=0. These starting concentrations are known, not fitted.

For each experiment, divide each concentration residual by the largest absolute
measured value of that concentration in that experiment. Take the square root
of the mean of all those squared residuals (both concentrations and all times).
The overall loss is the average of the two experiment losses, with equal weight
for each experiment. Save the measured and simulated A and B against time for
both experiments.
